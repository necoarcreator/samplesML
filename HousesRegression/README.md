# Предсказание цен квартир по табличным данным

Использовались анонимизированные данные агрегратора поиска квартир,
в которых лежали необработанные признаки. Часть данных была размечена, 
а часть - отправлялась в тест. 
Я предобрабатывал данные вручную (Pandas, Numpy, random), заполнял пропуски.
Из градиентных бустингов лучше себя показал CatBoost (неудивительно, в датасете
много категориальных признаков), а самописная нейросеть на PyTorch добивалась 
метрик ненамного ниже CatBoost'a. Оптимизация гиперпараметров 
проводилась с Optuna при помощи RandomSampler и MedianPruner.
Попытки в стекинг не увенчались успехом - слишком мало моделей для метамодели,
слишком мало времени (на момент соревнования) для оптимизации.


## Требования

- Python 3.8+
- Установленные зависимости (указаны в requirements.txt)
- CUDA-совместимая видеокарта
  
## Установка

Как установить зависимости:
- Для Python: `pip install -r requirements.txt`
- Распаковать данные из .zip файла (train и test)
## Запуск

Как запустить:
- Python: `jupyter notebook`
