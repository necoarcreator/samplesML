# Кластеризация долларовых миллиардеров на основе карты Кохонена 

Использовался датасет Kaggle https://www.kaggle.com/datasets/roysouravcu/forbes-billionaires-of-2021
С использованием C++11 был написан класс-предобработчик данных readerEncoder, класс-нормализатор Normalizer 
и класс, в котором реализован сам алгоритм машинного обучения KohonenMap.

Визуализация осуществляется с помощью Plotly, Seaborn, Matplotlib в файле analysis.ipynb

## Требования

- g++ (или любой совместимый C++11 компилятор)
- GNU Make
- ОС Linux / macOS (на Windows можно собрать через WSL или MinGW)
  
## Установка

Как установить зависимости:
- Для Python: `pip install -r requirements.txt` или `conda env create -f environment.yml`
- Для C++: `mkdir build && cd build && cmake .. && make`

## Запуск

Как запустить:
- Python: `jupyter notebook`
- C++: `make && make run`
Чтобы пересобрать проект - `make rebuild`

## Пример использования

#include "KohonenMap.h"

using namespace std;
int main()
{
	//вызов алгоритма, при его инициализации происходит обработка данных из файла
	KohonenMap A(10, true);

  //Обучение на трейновых данных
  //Первый параметр (int) - тип проверки сходимости обучения (представляет собой заглушку, реально не используется), 
  //второй (double) - точность, при которой считается, что достигнута сходимость,
  //третий (int) - максимальное число эпох при обучении,
  //четвёртый (double) - скорость обучения
  
	A.training(0, 1e-7, 200, 0.5);

  //вывод в стандартный поток информации о том, сколько сэмплов было "притянуто" в каждую из ячеек 
	A.printClusterization();

 //вывод в файл "KohonenMap.txt" полученных распределений
	A.writeToFile();
	
  //Кластеризация на искуственно созданных тестовых данных:
  //первый параметр (int) - какую по порядку сотню семплов взять в качестве теста,
  //второй параметр (int) - на сколько процентов изменить данные,
  //третий (bool) - нужен для проверки, запущен ли алгоритм после обучения или без предварительного обучения.
	A.clusterize(1, 5, true); 
	
	return 0;

}
