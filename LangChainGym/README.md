# Эксперименты с LangChain & LangGraph
Здесь лежит ноутбук с моими агентами на LangChain, которых я написал, в первую очередь, для образовательных целей.
В ноутбуке всё идёт от простого к сложному: от простейшего графа - greeter'а до полноценного RAG-агента с векторной БД Chroma, ретривером all-MiniLM-L6-v2, 
загруженным локально и генератором llama-3.1-8b-instant через langchain_groq API.  
*Note: проект вдохновлён видео по LangGraph от freeCodeCamp [https://www.youtube.com/watch?v=jGg_1h0qzaM&t=9004s&ab_channel=freeCodeCamp.org](https://youtu.be/jGg_1h0qzaM?si=cGYI0Wf7Y9PI0PEc)
Без этого туториала этого проекта не было бы.*
