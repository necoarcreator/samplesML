# Проекты по классическому ML, NLP и CV
В этом репозитории находятся мои проекты по машинному обучению,
среди них есть как учебные, так и реальные.
Часть написана на C++11 с самописными алгоритмами, а часть 
реализована на Python3 и использует готовые 
фреймворки и библиотеки.
Для удобства просмотра **проекты перечислены по дате добавления в обратном порядке**. 

## Создание планов лекций с помощью дообученного Qwen-3-0.6B
Часто курсы лекций, загруженные на Youtube, не имеют достаточного описания и плана.
Базовая модель галлюцинирует, пишет ненужные детали, формулы, отвечает на английском,
отвечает на вопросы в зал и отказывается отвечать из-за алаймента.
Решение было направлено на то, чтобы создать компактную и точную модель для суммаризации 
текста. 
Чтобы решить эту задачу, я создал пайплайн: 
1. Скачивание видео в формате .mp3
2. ASR с Whisper-V3-Large-ru
3. Разметка данных и создание синтетического датасета с OpenAI GPT-OSS-120b + prompt engineering
4. Дообучение Qwen-3-0.6B с квантизацией BitsAndBytes с помощью QLoRA
5. Деплой с fastAPI + Docker
## RAG для системы "вопрос-ответ"
Воинские уставы - то ещё испытание для курсантов военной кафедры, 
это решение было направлено на помощь в их освоении.
Уставы парсились с использованием регулярных выражений, 
обрабатывались ретривером ruBERT, загружались в FAISS-БД
по косинусному сходству, а генератор Qwen2.5 предоставлялся по API
Gradio-Client. Метрика - BERTScore F1.

## Дообучение ResNet для классификации Симпсонов
Учебный проект, в котором я знакомился с Pytorch, 
дообучением глубоких нейросетей. ResNet152 запускается локально
(как импортированная из torchvision.models),
веса первых N слоёв заморожены, в конце добавлен линейный слой для
классификации 42 персонажей.
Обучение происходит на датасете с изображениями Симпсонов.
Метрика - accuracy.
## Предсказание цен квартир по табличным данным
Соревнование на Kaggle, проведённое среди слушателей курса
по машинному обучению в МИФИ. Цель - по метрике MAPE 
обогнать решения других участников, пользуясь какими угодно
алгоритмами и библиотеками.
Моё лучшее решение - CatBoost с оптимизацией гиперпараметров с помощью
Optuna. Была попытка использования стэкинга самописной нейросети, SVR
и CatBoost, но она показала результаты не лучше, чем у CatBoost'а 
в отдельности.
