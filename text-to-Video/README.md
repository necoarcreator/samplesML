# Тестовое задание с генерацией видео по тексту и улучшением другого текста с помощью LLM.
    Задание разбито на две части.
## Первое задание: сгенерировать видео с помощью нейросетей.
Использовались оупенсорсные text-to-video-ms-1.7b и audioldm, они генерировали контент раздельно, 
а потом видео склеивалось с аудио. Лишние файлы удалялись.  
Пример нагенерированного - **final_video.mp4**
## Второе задание: улучшить текст, сделав его качественнее с т.з. маркетинга.
Был написан технический промпт, к нему добавился запрос.
Далее, был выполнен запрос по api к модели mistral-7b.  
Пример изменённого текста - **second_task_output.txt**
## Требования

- Python 3.8+
- Установленные зависимости (указаны в requirements.txt)
  
## Установка

Как установить зависимости:
- Для Python: `pip install -r requirements.txt`
Возможно создание Docker-образа (хотя у меня на ПК не хватило памяти для этого):
docker build -t video-and-text-gen .


## Запуск

Как запустить:
- Python: `jupyter notebook`
  
Если удалось собрать Docker-образ, то
- docker run -d -p 8000:8000 video-and-text-gen
- Открыть в браузере http://localhost:8000
